# Блок 3. SQL

Сложный SQL автоматизаторам почти не дают: `SELECT` с условием, сортировка, `JOIN`, изредка группировка. Синтаксис должен отскакивать, и надо уметь объяснить, зачем в запросе каждая часть.

| # | Задача | Сложность |
|---|---|---|
| 3.1 | [users и orders](3.1-users-and-orders.md) | легкая |
| 3.2 | [JOIN без WHERE](3.2-join-without-where.md) | сложная |

## Файлы

- [`setup.sql`](setup.sql) - таблицы и данные для 3.1.
- [`bank-schema.sql`](bank-schema.sql) - упрощенная банковская схема для 3.2.
- [`solutions.sql`](solutions.sql) - запросы из разборов.

Запускаются в любом PostgreSQL: DBeaver, psql или онлайн-песочница.
