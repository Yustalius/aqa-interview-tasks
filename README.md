# Задачи с собеседований на Java AQA

26 задач, которые реально давали на собеседованиях автоматизаторов на Java: Озон, Сбер, Ланит, Right Line и другие компании. К каждой есть разбор: что ответить, почему именно так и как починить.

Задачи и разборы собраны по итогам двух созвонов менторской группы. Разбор написан так, как его можно рассказать на собеседовании: коротко и по делу.

## Как пользоваться

1. Открой задачу и прочитай условие.
2. Ответь сам: вслух или письменно, 2–3 минуты, без IDE.
3. Только потом раскрывай блок **«Решение»** и сверяйся.
4. Код из блоков 1–3 можно запустить и проверить себя, инструкция [ниже](#как-запустить-код).

Сложность: 🟢 разминка · 🟡 надо подумать · 🔴 с подвохом

## Как отвечать на задачах

- **Сначала что, потом почему, потом как починить.** «Выведет `1 3 5`, потому что счётчик растёт дважды, уберу `i++` из тела».
- **Рассуждай вслух.** Интервьюер оценивает ход мысли. Если код не пишется, озвучь алгоритм словами: это уже половина ответа.
- **Задавай уточняющие вопросы.** В формате поля, в странном ассерте или в непонятном методе часто и спрятан подвох. Вопрос показывает, что ты его заметил.
- **Забыть синтаксис нормально.** Можно спросить, как называется метод, или сказать «тут нужен `LIKE`, не помню, процент или звёздочка». Это никого не смущает.
- **Незнакомый язык читай как английский.** JavaScript, bash, Dockerfile: `if`, `then`, `add`, `run`, `copy` переводятся буквально. Найди знакомое и оттолкнись от него.
- **На ревью сначала перескажи, потом критикуй.** Кто ищет ошибки в коде, который ещё не понял, выглядит хуже того, кто спокойно разобрал код и потом прошёлся по проблемам.
- **В задачах на баги одного правильного ответа обычно нет.** Оценивают структуру рассуждений, а не угаданную причину.

## Как запустить код

Нужна Java 11+. Gradle и IDE не нужны: файлы запускаются напрямую.

```bash
cd 01-java-snippets
java Snippets.java          # список задач
java Snippets.java 1.9      # запустить сниппет задачи 1.9

cd ../02-live-coding
java Practice.java 2.2      # своя реализация
java Solution.java 2.2      # эталонное решение
```

В Windows-терминале перед запуском выполни `chcp 65001`, иначе кириллица превратится в кракозябры.

SQL из блока 3 проверяется в любом PostgreSQL: выполни `setup.sql` (для 3.1) или `bank-schema.sql` (для 3.2) в DBeaver, psql или онлайн-песочнице, затем запросы из `solutions.sql`.

Сначала отвечай сам, потом запускай и сверяйся. Если запустить раньше времени, ничего не поймёшь.
