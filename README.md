# Задачи с собеседований на Java AQA

26 задач с реальных собеседований автоматизаторов на Java: Озон, Сбер, Ланит, Right Line и другие компании. К каждой задаче есть разбор: ответ, объяснение и исправленный код. Задачи разбирали на двух созвонах менторской группы.

## Как пользоваться

Прочитай условие и ответь сам, вслух или письменно, без IDE. Потом раскрой "Решение" и сверься. Код из блоков 1-3 можно запустить, инструкция [ниже](#как-запустить-код).

## Как отвечать на задачах

- Сначала скажи, что произойдет, потом почему, потом как починить. Например: "выведет `1 3 5`, счетчик растет дважды, уберу `i++` из тела".
- Рассуждай вслух. Если код не пишется, опиши алгоритм словами, за это уже дают часть баллов.
- Задавай уточняющие вопросы. Подвох часто сидит в формате поля, лишнем ассерте или странном методе.
- Синтаксис забывают все. Можно спросить название метода или сказать "тут `LIKE`, не помню, процент или звездочка".
- Незнакомый язык (JavaScript, bash, Dockerfile) читай как английский текст: `if`, `then`, `add`, `run`, `copy`. Найди знакомое и отталкивайся от него.
- На ревью сначала перескажи код, потом критикуй.
- В задачах на баги одного правильного ответа обычно нет, оценивают ход рассуждений.

## Как запустить код

Нужна Java 11+, Gradle и IDE не нужны.

```bash
cd 01-java-snippets
java Snippets.java          # список задач
java Snippets.java 1.9      # запустить сниппет задачи 1.9

cd ../02-live-coding
java Practice.java 2.2      # своя реализация
java Solution.java 2.2      # эталонное решение
```

В Windows-терминале сначала выполни `chcp 65001`, иначе кириллица в выводе сломается.

SQL из блока 3 запускается в любом PostgreSQL (DBeaver, psql, онлайн-песочница): сначала `setup.sql` для 3.1 или `bank-schema.sql` для 3.2, потом запросы из `solutions.sql`.
