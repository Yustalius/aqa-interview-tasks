# Блок 5. Локализация бага и разбор ответов API

Формат: «вот что-то не работает» или «вот такой ответ прилетел, что скажешь?». Проверяют, умеешь ли ты структурно искать причину и не останавливаешься ли на первой гипотезе.

Единственно правильного ответа здесь обычно нет. Оценивают рассуждения: что проверяешь, в каком порядке и какие делаешь выводы.
