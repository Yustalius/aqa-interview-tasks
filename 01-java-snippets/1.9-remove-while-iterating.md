# 1.9 · Удаление во время итерации

Ланит · тема: коллекции · сложность: сложная

Интервьюер сказал про эту задачу так: самый короткий сниппет с наибольшим количеством ловушек, и никто еще не нашел все.

## Условие

Что произойдет при запуске?

```java
public class CollectionTrap {
    public static void main(String[] args) {
        List<String> list = Arrays.asList("a", "b", "c", "d");
        for (String s : list) {
            if (s.equals("c")) {
                list.remove(s);
                System.out.println(list);
            }
        }
    }
}
```

Ловушек три. Иди по шагам:

1. Что произойдет с кодом как есть?
2. Починили первую проблему. Что теперь?
3. Меняем `"c"` на `"b"`. Что изменилось?

<details>
<summary><b>Решение</b></summary>

**Ловушка 1: список фиксированного размера.** `Arrays.asList` возвращает обертку над массивом, а размер массива не меняется. На `list.remove(s)` прилетит `UnsupportedOperationException`, вывода не будет.

**Ловушка 2: исключения нет.** Оборачиваем в обычный `ArrayList`:

```java
List<String> list = new ArrayList<>(Arrays.asList("a", "b", "c", "d"));
```

Кажется, что будет `ConcurrentModificationException`, но код отработает без ошибок и выведет `[a, b, d]`.

For-each работает через итератор. Перед каждым шагом итератор вызывает `hasNext()`, который сравнивает текущую позицию с размером списка. После удаления `"c"` размер стал 3, позиция тоже 3, `hasNext()` вернул `false`, и цикл закончился до проверки на изменение списка. Удаление предпоследнего элемента - единственный случай без исключения. Ошибки нет, но последний элемент цикл так и не проверил.

**Ловушка 3: `"b"` вместо `"c"`.** Выведется `[a, c, d]`, после чего упадет `ConcurrentModificationException`. После удаления размер 3, позиция 2, `hasNext()` вернул `true`, и следующий `next()` заметил, что список изменили в обход итератора.

**Как удалять правильно.**

```java
// через итератор
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    if (it.next().equals("c")) {
        it.remove();
    }
}

// или короче, Java 8+
list.removeIf(s -> s.equals("c"));
```
