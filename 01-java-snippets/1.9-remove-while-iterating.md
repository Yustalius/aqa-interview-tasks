# 1.9 · Удаление во время итерации

🔴 с подвохом · тема: коллекции · Ланит

Интервьюер сказал про эту задачу так: самый короткий сниппет с наибольшим количеством ловушек, и никто ещё не нашёл все.

## Условие

Что произойдёт при запуске?

```java
public class CollectionTrap {
    public static void main(String[] args) {
        List<String> list = Arrays.asList("a", "b", "c", "d");
        for (String s : list) {
            if (s.equals("c")) {
                list.remove(s);
                System.out.println(list);
            }
        }
    }
}
```

Ловушек три. Чтобы найти все, иди по шагам:

1. Что произойдёт с кодом как есть?
2. Починили первую проблему. Что теперь?
3. Меняем `"c"` на `"b"`. Что изменилось?

<details>
<summary><b>Решение</b></summary>

**Ловушка 1: список фиксированного размера.** `Arrays.asList` возвращает обёртку над массивом, а у массива размер не меняется. Удалять из такого списка нельзя: на `list.remove(s)` прилетит `UnsupportedOperationException`. Вывода не будет.

**Ловушка 2: ожидаешь исключение, а его нет.** Оборачиваем в обычный `ArrayList`:

```java
List<String> list = new ArrayList<>(Arrays.asList("a", "b", "c", "d"));
```

Все ждут `ConcurrentModificationException`, но код отработает без ошибок и выведет `[a, b, d]`.

Почему: for-each работает через итератор. Перед каждым шагом итератор вызывает `hasNext()`, а тот сравнивает текущую позицию с размером списка. После удаления `"c"` размер стал 3, позиция тоже 3, `hasNext()` вернул `false`, и цикл тихо закончился, не дойдя до проверки на изменение списка. Удаление **предпоследнего** элемента — единственный случай, когда исключения нет. Это самая коварная ловушка: код «работает», но молча пропускает последний элемент.

**Ловушка 3: меняем `"c"` на `"b"`.** Выведется `[a, c, d]`, после чего упадёт `ConcurrentModificationException`. После удаления размер 3, позиция 2, `hasNext()` вернул `true`, и следующий `next()` заметил, что список изменили в обход итератора.

**Как удалять правильно.**

```java
// через итератор
Iterator<String> it = list.iterator();
while (it.hasNext()) {
    if (it.next().equals("c")) {
        it.remove();
    }
}

// или короче, Java 8+
list.removeIf(s -> s.equals("c"));
```
