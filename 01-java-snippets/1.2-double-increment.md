# 1.2 · Двойной инкремент в цикле

Тема: циклы · сложность: легкая

## Условие

Код должен выводить числа от 1 до 5. Найди ошибку, объясни, почему код работает не так, и предложи исправление. Какие еще проблемы есть в коде?

```java
public class LoopError {
    public static void main(String[] args) {
        for (int i = 1; i <= 5; ++i) {
            System.out.println(i);
            i++;
        }
    }
}
```

Дополнительный вопрос: что выведется, если условие поменять на `i < 5`?

<details>
<summary><b>Решение</b></summary>

**Ответ.** Выведет `1 3 5`.

**Почему.** Счетчик растет дважды за итерацию: в `i++` внутри тела и в `++i` в заголовке цикла.

| Итерация | Печатаем | После `i++` в теле | После `++i` в заголовке |
|---|---|---|---|
| 1 | 1 | 2 | 3 |
| 2 | 3 | 4 | 5 |
| 3 | 5 | 6 | 7, условие `7 <= 5` ложно, выход |

**Как починить.** Убрать `i++` из тела, счетчиком управляет заголовок цикла. Менять счетчик еще и в теле - вторая проблема кода: даже когда так работает, цикл трудно читать.

**`++i` или `i++`.** Здесь разницы нет. `++i` сначала увеличивает и возвращает новое значение, `i++` возвращает старое и потом увеличивает. Разница видна, только если результат присваивают:

```java
int a = 5;
int b = a++;   // b = 5, a = 6
int c = ++a;   // a = 7, c = 7
```

В заголовке цикла результат никуда не присваивается.

**Если условие `i < 5`.** Выведет `1 3`: после второй итерации `i` равен 5, а `5 < 5` ложно.

</details>
