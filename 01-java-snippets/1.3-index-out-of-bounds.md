# 1.3 · Выход за границы списка

🟢 разминка · тема: коллекции

## Условие

Что произойдёт после выполнения кода и почему? Если есть ошибка, как её исправить?

```java
import java.util.ArrayList;
import java.util.List;

public class ListError {
    public static void main(String[] args) {
        List<Integer> numbers = new ArrayList<>();

        numbers.add(1);
        numbers.add(2);
        numbers.add(3);

        for (int i = 0; i <= numbers.size(); i++) {
            System.out.println(numbers.get(i));
        }
    }
}
```

Ответ «упадёт с ошибкой» не засчитывается: назови исключение, итерацию и то, что успеет вывестись.

<details>
<summary><b>Решение</b></summary>

**Ответ.** Выведет `1`, `2`, `3`, а на четвёртой итерации (`i = 3`) упадёт с
`IndexOutOfBoundsException: Index 3 out of bounds for length 3`.

**Почему.** Индексы начинаются с нуля: у списка из трёх элементов валидны индексы 0, 1 и 2. `numbers.size()` возвращает 3, а условие `i <= 3` пускает цикл и на `i = 3`, где элемента нет.

**Как починить.** Минимально заменить `<=` на `<`. Лучше перейти на for-each: индексов там нет, и выйти за границы невозможно в принципе.

```java
for (Integer number : numbers) {
    System.out.println(number);
}
```

</details>
