# 1.3 · Выход за границы списка

Тема: коллекции · сложность: легкая

## Условие

Что произойдет после выполнения кода и почему? Если есть ошибка, как ее исправить?

```java
import java.util.ArrayList;
import java.util.List;

public class ListError {
    public static void main(String[] args) {
        List<Integer> numbers = new ArrayList<>();

        numbers.add(1);
        numbers.add(2);
        numbers.add(3);

        for (int i = 0; i <= numbers.size(); i++) {
            System.out.println(numbers.get(i));
        }
    }
}
```

Ответ "упадет с ошибкой" не засчитывают: назови исключение, итерацию и то, что успеет вывестись.

<details>
<summary><b>Решение</b></summary>

**Ответ.** Выведет `1`, `2`, `3`, а на четвертой итерации (`i = 3`) упадет с
`IndexOutOfBoundsException: Index 3 out of bounds for length 3`.

**Почему.** Индексы начинаются с нуля, у списка из трех элементов валидны 0, 1 и 2. `numbers.size()` возвращает 3, условие `i <= 3` пускает цикл на `i = 3`, а элемента с таким индексом нет.

**Как починить.** Заменить `<=` на `<`. Надежнее for-each: в нем нет индексов, и выйти за границы нельзя.

```java
for (Integer number : numbers) {
    System.out.println(number);
}
```

</details>
