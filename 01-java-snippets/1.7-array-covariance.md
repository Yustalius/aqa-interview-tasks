# 1.7 · Ковариантность массивов

Ланит · тема: массивы и дженерики · сложность: средняя

## Условие

Выполнится ли этот код? Почему?

```java
public class Main {
    public static void main(String[] args) {
        Object[] objects = new String[3];
        objects[0] = "hello";
        objects[1] = 42;
    }
}
```

Дополнительно: что будет, если сделать то же самое с `List`?

<details>
<summary><b>Решение</b></summary>

**Ответ.** Код скомпилируется, но упадет при выполнении на строке `objects[1] = 42` с `ArrayStoreException: java.lang.Integer`.

**Почему.** Массивы в Java ковариантны: `String` наследуется от `Object`, поэтому `String[]` можно присвоить переменной типа `Object[]`. Компилятор видит тип `Object[]`, в который можно положить что угодно, и ошибок не находит.

В памяти же лежит массив строк, и при каждой записи он проверяет тип элемента. `"hello"` проходит, а `42` после автоупаковки становится `Integer` и в массив строк не помещается.

`3` в `new String[3]` - размер массива, а не элемент.

**С `List` так не получится:**

```java
List<Object> list = new ArrayList<String>(); // ошибка компиляции
```

Дженерики инвариантны: `List<String>` не подтип `List<Object>`. Такая ошибка ловится при компиляции. Дженерики так и сделали, чтобы не повторить проблему массивов.

</details>
