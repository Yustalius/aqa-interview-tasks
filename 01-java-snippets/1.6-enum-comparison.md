# 1.6 · Сравнение enum

🟢 разминка · тема: enum · Ланит

## Условие

Что выведет код?

```java
public class EnumComparisonDemo {
    enum Color { RED, GREEN, BLUE }

    public static void main(String[] args) {
        Color a = Color.RED;
        Color b = Color.RED;

        System.out.println(a == b);
        System.out.println(a.equals(b));
    }
}
```

Эту задачу дали сразу после [1.5](1.5-string-pool.md) не случайно. В чём разница со строками?

<details>
<summary><b>Решение</b></summary>

**Ответ.** `true` и `true`.

**Почему.** Каждая константа enum существует в программе в **единственном экземпляре**. Сколько ни присваивай `Color.RED`, это всегда один и тот же объект. Поэтому `==` сравнивает одинаковые ссылки и даёт `true`. У enum `equals` внутри и есть `==`, поэтому тоже `true`.

**Разница со строками.** Одинаковые строки могут оказаться разными объектами (одна в пуле, другая собрана в рантайме), поэтому `==` для строк ненадёжен. Одинаковые константы enum гарантированно один объект.

Для enum сравнение через `==` даже предпочтительнее: оно не падает на `null`. Если `a = null`, то `a == b` просто вернёт `false`, а `a.equals(b)` выбросит `NullPointerException`.

**Где это в автотестах.** Статусы (заказа, пользователя, теста) удобно держать в enum, а не в строках: опечатку в `"ACTVE"` компилятор не заметит, а в `Status.ACTVE` заметит сразу.

</details>
