# 1.6 · Сравнение enum

Ланит · тема: enum · сложность: легкая

## Условие

Что выведет код?

```java
public class EnumComparisonDemo {
    enum Color { RED, GREEN, BLUE }

    public static void main(String[] args) {
        Color a = Color.RED;
        Color b = Color.RED;

        System.out.println(a == b);
        System.out.println(a.equals(b));
    }
}
```

Задачу дали сразу после [1.5](1.5-string-pool.md). Чем этот случай отличается от строк?

<details>
<summary><b>Решение</b></summary>

**Ответ.** `true` и `true`.

**Почему.** Каждая константа enum существует в программе в одном экземпляре. Сколько ни присваивай `Color.RED`, это всегда один объект, поэтому `==` дает `true`. `equals` у enum внутри сравнивает через `==`, поэтому тоже `true`.

**Отличие от строк.** Одинаковые строки могут оказаться разными объектами (одна в пуле, другая собрана в рантайме), поэтому для строк `==` ненадежен. Одинаковые константы enum всегда один объект.

Для enum `==` даже удобнее `equals`, потому что не падает на `null`. Если `a = null`, то `a == b` вернет `false`, а `a.equals(b)` выбросит `NullPointerException`.

**При чем тут автотесты.** Статусы заказа, пользователя или теста удобно держать в enum вместо строк: опечатку в `"ACTVE"` компилятор пропустит, а `Status.ACTVE` не скомпилируется.

</details>
