# 1.1 · Нестатический метод из `main`

🟢 разминка · тема: `static`

## Условие

Что произойдёт при запуске? Если есть ошибка, как её исправить?

```java
public class Hello {
    public static void main(String[] args) {
        sayHello();
    }

    public void sayHello() {
        System.out.println("Привет, мир!");
    }
}
```

Дополнительно спрашивают: какие есть два способа починить и почему `main` вообще статический.

<details>
<summary><b>Решение</b></summary>

**Ответ.** Код не скомпилируется: `non-static method sayHello() cannot be referenced from a static context`.

**Почему.** Статический метод принадлежит классу и вызывается без объекта. Нестатический `sayHello()` принадлежит конкретному объекту и может работать с его полями.

Представь, что у `Hello` есть поле `name` и созданы два объекта, «Вася» и «Петя». Если бы `main` мог вызвать `sayHello()` напрямую, было бы непонятно, чьё имя печатать. Объектов может вообще не быть. Поэтому Java запрещает обращаться к нестатическому коду из статического.

**Как починить.**

```java
// Способ 1: сделать метод статическим
public static void sayHello() {
    System.out.println("Привет, мир!");
}

// Способ 2: создать объект и вызвать метод у него
public static void main(String[] args) {
    new Hello().sayHello();
}
```

Когда какой: если метод не трогает поля объекта, его делают `static`, это утилитный метод. Если метод описывает поведение объекта, создают объект. Здесь метод просто печатает строку, поэтому уместнее `static`.

**Почему `main` статический.** Это точка входа в программу. JVM вызывает его, когда ещё не создано ни одного объекта. Будь `main` нестатическим, кому-то пришлось бы сначала создать объект, а создавать его ещё некому.

</details>
