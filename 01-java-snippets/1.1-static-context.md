# 1.1 · Нестатический метод из `main`

Тема: static · сложность: легкая

## Условие

Что произойдет при запуске? Если есть ошибка, как ее исправить?

```java
public class Hello {
    public static void main(String[] args) {
        sayHello();
    }

    public void sayHello() {
        System.out.println("Привет, мир!");
    }
}
```

Дополнительные вопросы: два способа починить и почему `main` статический.

<details>
<summary><b>Решение</b></summary>

**Ответ.** Код не скомпилируется: `non-static method sayHello() cannot be referenced from a static context`.

**Почему.** Статический метод принадлежит классу и вызывается без объекта. `sayHello()` нестатический: он принадлежит объекту и может читать его поля. Допустим, у `Hello` есть поле `name` и созданы два объекта, Вася и Петя. Из `main` непонятно, чье имя печатать, а объектов может не быть вовсе. Поэтому из статического кода нестатический напрямую вызвать нельзя.

**Как починить.**

```java
// Способ 1: сделать метод статическим
public static void sayHello() {
    System.out.println("Привет, мир!");
}

// Способ 2: создать объект и вызвать метод у него
public static void main(String[] args) {
    new Hello().sayHello();
}
```

Метод не работает с полями объекта, поэтому здесь лучше `static`. Если бы метод использовал состояние объекта, подошел бы второй способ.

**Почему `main` статический.** JVM вызывает `main` при старте программы, когда объектов еще нет. Будь он нестатическим, для вызова пришлось бы сначала создать объект, а создать его некому.

</details>
