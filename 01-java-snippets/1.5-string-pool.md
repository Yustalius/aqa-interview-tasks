# 1.5 · Сравнение строк

Ланит · тема: String pool · сложность: средняя

## Условие

Что выведет код?

```java
public class StringConcatenationDemo {
    public static void main(String[] args) {
        String s1 = "Hello" + " World";
        String s2 = "Hello World";

        String part = " World";
        String s3 = "Hello" + part;

        System.out.println(s1 == s2);
        System.out.println(s2 == s3);
    }
}
```

Вопрос интервьюера: как сделать второе сравнение `true`? Назови два способа.

<details>
<summary><b>Решение</b></summary>

**Ответ.**

```
true
false
```

**Почему.** Строковые литералы Java хранит в пуле строк, каждый в одном экземпляре. Если в двух местах программы написать `"Hello World"`, обе переменные получат ссылку на одну строку из пула.

- `s1 = "Hello" + " World"` склеивает два литерала. Компилятор делает это заранее, и в коде остается литерал `"Hello World"` из пула. `s2` указывает туда же, поэтому `s1 == s2` дает `true`.
- `s3 = "Hello" + part` склеивает литерал с переменной. Компилятор не знает, что будет в `part` во время выполнения, поэтому строка собирается в рантайме новым объектом мимо пула. Ссылки разные, `s2 == s3` дает `false`.

**Два способа получить `true`.**

```java
// 1. final: переменная становится константой,
//    и компилятор снова склеит строку заранее
final String part = " World";

// 2. intern(): вручную взять строку из пула
System.out.println(s2 == s3.intern());
```

И добавь, что в рабочем коде строки сравнивают только через `equals`. Результат `==` зависит от того, откуда пришла строка, и это дает плавающие баги.

</details>
