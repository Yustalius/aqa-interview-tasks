# 1.4 · Сравнение объектов

🟢 разминка · тема: ссылки · Озон, технический скрининг

Собеседование на Java-автоматизатора, а задача на JavaScript. Так бывает: механика сравнения от языка почти не зависит. Если не знаешь синтаксис, спроси, что значит `let`. Это нормальный вопрос.

## Условие

Что выведет консоль?

```javascript
let a = {
    a: 1
}
let b = {
    a: 1
}
let c = a

console.log(a === b) // output: ???
console.log(a === c) // output: ???
```

Дополнительно: перепиши на Java. Что изменится, если сравнить через `a.equals(b)`?

<details>
<summary><b>Решение</b></summary>

**Ответ.**

```
a === b  →  false
a === c  →  true
```

**Почему.** `a` и `b` — два разных объекта, хоть и с одинаковым содержимым. Для объектов `===` сравнивает ссылки, то есть проверяет, один ли это объект в памяти. `c = a` не создаёт новый объект, а копирует ссылку, поэтому `a` и `c` указывают на одно и то же.

**На Java то же самое:**

```java
Point a = new Point(1);
Point b = new Point(1);
Point c = a;

System.out.println(a == b); // false: разные объекты
System.out.println(a == c); // true: одна ссылка
```

**А `a.equals(b)`?** Зависит от класса. Если `equals` не переопределён, он работает как `==` и вернёт `false`. Если переопределён на сравнение полей (как у `String`, `Integer` или DTO с Lombok `@Data`), вернёт `true`.

Короткая формула для собеса: `==` сравнивает ссылки, `equals` сравнивает содержимое, если класс этому научили.

</details>
