# 1.4 · Сравнение объектов

Озон, технический скрининг · тема: ссылки · сложность: легкая

Собеседование было на Java, а задачу дали на JavaScript. Сравнение объектов в обоих языках устроено одинаково. Незнакомый синтаксис можно уточнить у интервьюера, например спросить, что значит `let`.

## Условие

Что выведет консоль?

```javascript
let a = {
    a: 1
}
let b = {
    a: 1
}
let c = a

console.log(a === b) // output: ???
console.log(a === c) // output: ???
```

Дополнительно: перепиши на Java. Что изменится, если сравнить через `a.equals(b)`?

<details>
<summary><b>Решение</b></summary>

**Ответ.**

```
a === b  →  false
a === c  →  true
```

**Почему.** `a` и `b` - два разных объекта с одинаковым содержимым. Для объектов `===` сравнивает ссылки, то есть проверяет, один ли это объект в памяти. `c = a` копирует ссылку, поэтому `a` и `c` указывают на один объект.

**На Java то же самое:**

```java
Point a = new Point(1);
Point b = new Point(1);
Point c = a;

System.out.println(a == b); // false: разные объекты
System.out.println(a == c); // true: одна ссылка
```

**`a.equals(b)`.** Зависит от класса. Если `equals` не переопределен, он работает как `==` и вернет `false`. Если переопределен на сравнение полей (как у `String`, `Integer` или DTO с Lombok `@Data`), вернет `true`.

Для собеса: `==` сравнивает ссылки, `equals` сравнивает содержимое, если класс его переопределил.

</details>
