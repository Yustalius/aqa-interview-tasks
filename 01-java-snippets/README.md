# Блок 1. Java: что выведет код

Самый частый формат технической секции. Интервьюер показывает код, ты читаешь его вслух и говоришь, что произойдёт и почему. Писать код не нужно.

Правило блока: сначала говоришь, **что** выведется, потом **почему**. Ответ «упадёт с ошибкой» не принимается: назови исключение и место, где оно прилетит.

## Запуск

Все сниппеты, кроме 1.1 и 1.4, собраны в [`Snippets.java`](Snippets.java):

```bash
java Snippets.java        # список задач
java Snippets.java 1.5    # запустить конкретную
```

1.1 не компилируется, а 1.4 написана на JavaScript, поэтому они лежат в комментариях.
