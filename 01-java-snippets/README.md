Сниппеты, кроме 1.1 и 1.4, собраны в [`Snippets.java`](Snippets.java):

```bash
java Snippets.java 1.5    # запустить конкретную
```

1.1 не компилируется, 1.4 написана на JavaScript, поэтому их код лежит в комментариях.
