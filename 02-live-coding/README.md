# Блок 2. Написать код

Писать код просят редко, в основном в бигтехе (Озон, Яндекс, Т-Банк, WB), где любят алгоритмы. В остальных компаниях чаще дают читать чужой код.

Пока пишешь, проговаривай, что делаешь: интервьюер смотрит на ход мысли. Забыл синтаксис - опиши алгоритм словами и спроси название метода.
