# Блок 2. Написать код

Задачи на написание кода дают редко: в основном в бигтехе (Озон, Яндекс, Т-Банк, WB), где любят алгоритмы. В остальных компаниях чаще просят прочитать чужой код.

Здесь важно не только написать решение, но и проговаривать вслух, что делаешь. Интервьюер оценивает ход мысли, а не скорость набора. Если синтаксис вылетел из головы, озвучь алгоритм словами и спроси название метода: это нормально.
