# 2.2 · Преобразование массива строк

🟢 разминка · тема: строки, Stream API · тестовое задание по ссылке

## Условие

> Напишите на Java метод, который принимает массив строк `String[]`.
>
> Для каждой строки необходимо:
> 1. заменить символ `'1'` на символ `'a'`;
> 2. преобразовать строку в верхний регистр;
> 3. развернуть строку в обратном порядке.
>
> Исходный массив изменять не нужно: метод должен вернуть новый массив с преобразованными строками.

```
Input:  ["he1lo", "java1", "123"]
Output: ["OLAEH", "AAVAJ", "32A"]
```

Интервьюер просил проговорить решение вслух, называя типы и методы. По ходу спрашивал:
- `toUpperCase()` меняет строку или возвращает новую?
- Можно ли написать то же самое функционально? Какие методы Stream API знаешь?

<details>
<summary><b>Решение</b></summary>

**Что сказать до кода.** «Пройду по массиву, к каждой строке применю три преобразования по порядку, результат сложу в новый массив той же длины. Разворачивать буду через `StringBuilder.reverse()`, у `String` такого метода нет».

**Через цикл:**

```java
public static String[] transform(String[] input) {
    String[] result = new String[input.length];        // новый массив, исходный не трогаем
    for (int i = 0; i < input.length; i++) {
        String s = input[i]
                .replace('1', 'a')                     // 1. замена
                .toUpperCase();                        // 2. верхний регистр
        result[i] = new StringBuilder(s).reverse().toString();  // 3. разворот
    }
    return result;
}
```

**Через Stream API:**

```java
public static String[] transform(String[] input) {
    return Arrays.stream(input)
            .map(s -> s.replace('1', 'a'))
            .map(String::toUpperCase)
            .map(s -> new StringBuilder(s).reverse().toString())
            .toArray(String[]::new);
}
```

`Arrays.stream` нужен, потому что у массива нет своих методов, в отличие от `List`. В конце `toArray` собирает поток обратно в массив.

**Сверься с примером.** `"123"` превращается в `"32A"`, а не в `"321"`. Порядок важен: `"123"` → замена → `"a23"` → регистр → `"A23"` → разворот → `"32A"`.

**Ответы на вопросы по ходу.**
- Строки в Java неизменяемые. `replace` и `toUpperCase` не меняют исходную строку, а возвращают новую. Поэтому исходный массив остаётся нетронутым.
- Методы Stream API, которые стоит знать: `filter`, `map`, `sorted`, `distinct`, `limit`, а из завершающих `toList` / `collect`, `count`, `anyMatch`, `findFirst`.
