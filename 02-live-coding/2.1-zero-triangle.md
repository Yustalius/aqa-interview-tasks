# 2.1 · Треугольник из нулей

🟡 надо подумать · тема: циклы · Озон, технический скрининг

## Условие

> Реализовать функцию, которая выведет треугольник из нулей со сторонами 5 на 5.

```
00000
0000
000
00
0
```

Язык на выбор.

<details>
<summary><b>Решение</b></summary>

**Что сказать до кода.** Строк пять, в первой пять нулей, в каждой следующей на один меньше. Значит, нужен внешний цикл по строкам, а длина строки равна номеру строки, если считать с конца. Уточни у интервьюера, зашить размер 5 в код или передать параметром. Лучше параметром.

```java
public static void printTriangle(int size) {
    for (int i = size; i >= 1; i--) {      // строки: длина от size до 1
        for (int j = 0; j < i; j++) {      // в строке печатаем i нулей
            System.out.print("0");
        }
        System.out.println();
    }
}
```

Внешний цикл отвечает за строки и их длину, внутренний печатает нули в текущей строке.

**Короче, Java 11+:**

```java
for (int i = size; i >= 1; i--) {
    System.out.println("0".repeat(i));
}
```

Вариант с вложенным циклом всё равно стоит знать: в алгоритмических задачах часто просят решить без готовых методов.

</details>
