# 2.1 · Треугольник из нулей

Озон, технический скрининг · тема: циклы · сложность: средняя

## Условие

> Реализовать функцию, которая выведет треугольник из нулей со сторонами 5 на 5.

```
00000
0000
000
00
0
```

Язык на выбор.

<details>
<summary><b>Решение</b></summary>

**Что сказать до кода.** Строк пять, в первой пять нулей, в каждой следующей на один меньше. Внешний цикл идет по строкам от 5 до 1, номер строки равен количеству нулей в ней. Уточни у интервьюера, зашить размер в код или передать параметром. Лучше параметром.

```java
public static void printTriangle(int size) {
    for (int i = size; i >= 1; i--) {      // строки: длина от size до 1
        for (int j = 0; j < i; j++) {      // в строке печатаем i нулей
            System.out.print("0");
        }
        System.out.println();
    }
}
```

**Короче, Java 11+:**

```java
for (int i = size; i >= 1; i--) {
    System.out.println("0".repeat(i));
}
```

Вложенный цикл все равно надо уметь написать: в алгоритмических задачах часто просят обойтись без готовых методов.

</details>
