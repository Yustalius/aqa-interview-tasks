# Блок 6. Code review

Дают чужой код и просят сказать, что с ним не так. Пишешь мало, в основном рассуждаешь вслух.

Как читать незнакомый код:

1. Сверху вниз. Сначала классы и методы и что они делают судя по названиям, потом тела методов.
2. Ищи знакомое: `==` и `equals`, `Thread.sleep`, Lombok, `@ParameterizedTest`.
3. Раздели замечания: не скомпилируется, работает неправильно, работает, но плохо.
4. Объясняй, чем проблема навредит автотестам: флаки, медленный прогон, ложнозеленые проверки.
