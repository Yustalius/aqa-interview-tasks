# Блок 6. Code review

Самый показательный блок. Дают чужой код и просят сказать, что с ним не так. Пишешь мало, в основном рассуждаешь вслух.

Как читать незнакомый код:

1. **Сверху вниз, от общего к частному.** Какие классы, какие методы, что они делают судя по названиям. Только потом в тело методов.
2. **Ищи знакомое.** Почти всё в таких задачах вы уже видели: `==` и `equals`, `Thread.sleep`, Lombok, `@ParameterizedTest`.
3. **Раздели замечания:** не скомпилируется / работает неправильно / работает, но плохо.
4. **Приземляй на автотесты.** Не просто «так плохо», а чем это выстрелит: флаки-тестами, медленным прогоном, ложнозелёными проверками.
