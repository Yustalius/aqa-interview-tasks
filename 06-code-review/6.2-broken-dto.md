# 6.2 · Сломанный DTO-класс

🟡 надо подумать · тема: Lombok, Jackson · Сбер, риск-стратегии

## Условие

Писать код не нужно. Проревьюй класс: скажи, что так, что не так, дай рекомендации. Рассуждай вслух.

Файл `BrokenStepDto.java`:

```java
package ru.test.my;

@Data
@FieldDefaults(level = AccessLevel.PRIVATE)
@AllArgsConstructor
@NoArgsConstructor
public class brokenStepDto {

    public String caseId;
    public String config_Id;
    private String name;
    // private String class;
    @JsonProperty("myTrace")
    private String Trace;
    private String dateStart

    public BrokenStepDto () {}

    public BrokenStepDto(String caseId, String config_Id, String name, String Trace, Date dateStart) {
        this.caseId = caseId;
        this.config_Id = config_Id;
        this.name = name;
        this.Trace = Trace;
        this.dateStart = dateStart;
    }

    public BrokenStepDto(String caseId, String name) {
        this.caseId = caseId;
        this.name = name;
    }

    public String getCaseId() {return caseId;}

    public void setCaseId(String caseId) {this.caseId = caseId;}

    public String getSpaceId() {return spaceId;}

    public void setSpaceId(String spaceId) {this.spaceId = spaceId;}
}
```

Финал задачи: перепиши класс так, как он должен выглядеть.

<details>
<summary><b>Решение</b></summary>

Удобнее всего разделить замечания на две группы: что не даст коду скомпилироваться и что скомпилируется, но плохо. Всего проблем одиннадцать, на собесе столько не ждут, но чем больше, тем лучше.

### Не скомпилируется

1. **`brokenStepDto` с маленькой буквы**, а файл называется `BrokenStepDto.java`. Имя публичного класса обязано совпадать с именем файла. Да и классы в Java пишут с большой буквы.
2. Из-за этого конструкторы `BrokenStepDto(...)` не совпадают с именем класса, и компилятор считает их методами без типа возврата.
3. **`private String dateStart` без точки с запятой.**
4. **Типы не совпадают:** конструктор принимает `Date dateStart`, а поле объявлено как `String`.
5. **`getSpaceId` и `setSpaceId` обращаются к полю `spaceId`**, которого в классе нет.
6. **Нет импортов:** ни Lombok, ни `@JsonProperty`, ни `Date`. Помнить сами импорты не нужно, достаточно заметить, что их нет.
7. **Конструкторы-дубли.** Если починить имя класса, `@NoArgsConstructor` и `@AllArgsConstructor` сгенерируют конструкторы, которые уже написаны руками. Два одинаковых конструктора — ошибка компиляции.

### Скомпилируется, но плохо

8. **Ручные геттеры и сеттеры при `@Data`.** `@Data` уже генерирует их для всех полей. Либо Lombok, либо руками, но не вперемешку.
9. **Публичные поля.** У DTO поля закрыты, доступ через геттеры. `@FieldDefaults(level = PRIVATE)` делает приватными только поля без явного модификатора, а явный `public` он не трогает. Получилась каша: аннотация говорит одно, поля другое. Проще убрать `@FieldDefaults` и явно написать `private`.
10. **Нейминг.** `config_Id` — это snake_case, а `Trace` — с большой буквы. В Java поля пишут в camelCase: `configId`, `trace`. Если в JSON поле называется иначе, это решается через `@JsonProperty`.
11. **Закомментированный код.** `// private String class` надо либо удалить, либо вернуть. Причём `class` — зарезервированное слово, назвать так поле нельзя. Если такое поле есть в JSON, его называют по-другому и маппят:

    ```java
    @JsonProperty("class")
    private String clazz;
    ```

Отдельно стоит уточнить у интервьюера тип `dateStart`. Если это дата, лучше `LocalDateTime` из `java.time`, чем устаревший `java.util.Date`. И зачем `Trace` переименован в `myTrace`: если причины нет, проще назвать поле так же, как в JSON.

### Как должен выглядеть класс

```java
package ru.test.my;

import com.fasterxml.jackson.annotation.JsonProperty;
import lombok.AllArgsConstructor;
import lombok.Data;
import lombok.NoArgsConstructor;

@Data
@AllArgsConstructor
@NoArgsConstructor
public class BrokenStepDto {

    private String caseId;
    private String configId;
    private String name;

    @JsonProperty("myTrace")
    private String trace;

    private String dateStart;   // или LocalDateTime, уточнить формат
}
```

Lombok сгенерирует всё: геттеры, сеттеры, оба конструктора, `equals`, `hashCode`, `toString`. Если нужен конструктор на два поля, его можно оставить руками (Lombok такой не создаёт) или заменить на `@Builder`.
