# 7.2 · Тексты заголовков

Тема: локаторы, коллекции · сложность: легкая

## Условие

Код должен найти все заголовки `<h2>` на странице и вывести их тексты.

```java
import static com.codeborne.selenide.Selenide.$;
import static com.codeborne.selenide.Selenide.$$;

public class HeadingsPrinter {
    public static void main(String[] args) {
        // Находим заголовки
        $$("#h2").shouldHave(size(2));

        // Выводим текст каждого заголовка
        System.out.println($$("#h2").getText());
    }
}
```

Вопросы интервьюера по порядку:
1. Что делает этот код?
2. Есть ли в нем ошибка? Если да, какая?
3. Как исправить код, чтобы он работал корректно?
4. Что означает `getText()` у `$$` и у `$`?

<details>
<summary><b>Решение</b></summary>

**Что делает код.** Ищет элементы по селектору `#h2`, проверяет, что их два, и пытается вывести их текст.

**Ошибок две, и они разного сорта.**

1. Селектор (логика). В CSS `#` означает поиск по `id`, и `#h2` найдет элемент с `id="h2"`. Заголовки ищут по тегу: `$$("h2")` или `$$(byTagName("h2"))`.
2. Метод (компиляция). У коллекции `$$` нет метода `getText()`, код не скомпилируется.

Плюс мелочи как в [7.1](7.1-count-buttons.md): ассерт на два заголовка задаче не нужен, `size` не импортирован, `open()` нет.

**Как исправить.**

```java
open("https://example.com");

// все тексты разом: List<String>
System.out.println($$("h2").texts());

// или по одному элементу
for (SelenideElement heading : $$("h2")) {
    System.out.println(heading.getText());
}
```

**`getText()` у `$` и у `$$`.** `$("h2").getText()` возвращает текст первого найденного элемента, `String`. У `$$` метода `getText()` нет, тексты всех элементов возвращает `texts()` в виде `List<String>`.

</details>
