# 7.3 · Клик по кнопке с текстом

Тема: локаторы, клики · сложность: средняя

## Условие

Код должен нажать на кнопку с текстом "Подтвердить".

```java
import static com.codeborne.selenide.Selenide.$;

public class ButtonClickProblem {
    public static void main(String[] args) {
        // Находим кнопку
        $("button:contains('Подтвердить')").click();
    }
}
```

Вопросы интервьюера:
1. Почему кнопка может не кликаться?
2. Какие есть альтернативные способы кликнуть по кнопке в Selenide?
3. Как проверить, видна ли кнопка?
4. Как прокрутить страницу к кнопке, если она не в зоне видимости?
5. Как кликнуть через JavaScript, если обычный клик не работает?

<details>
<summary><b>Решение</b></summary>

**Главная ошибка.** Псевдокласса `:contains` в CSS нет, он из jQuery. Браузер его не понимает, и Selenide упадет с `InvalidSelectorException`. Он похож на CSS, и его до сих пор советуют старые статьи, поэтому ошибка частая.

По тексту в Selenide ищут так:

```java
$(byText("Подтвердить")).click();                    // точное совпадение текста
$$("button").findBy(text("Подтвердить")).click();    // среди кнопок, по вхождению текста
```

**1. Почему кнопка может не кликаться:**
- локатор ничего не находит, как здесь;
- кнопку перекрывает модалка, лоадер или баннер с куками;
- кнопка за пределами видимой области;
- кнопка еще не отрисовалась, страница грузится асинхронно;
- кнопка неактивна (`disabled`).

**2. Другие способы клика:** `click(ClickOptions.usingJavaScript())`, клик со смещением `click(ClickOptions.usingDefaultMethod().offset(x, y))`, `doubleClick()`, `contextClick()`, клик через `actions()`.

**3. Видна ли кнопка:** `$(...).shouldBe(visible)` ждет появления до таймаута, `isDisplayed()` проверяет сразу, без ожидания.

**4. Прокрутка:** `scrollTo()` прокручивает так, что элемент оказывается у края экрана, `scrollIntoCenter()` (Selenide 7) ставит его в центр. Обычный `click()` в Selenide прокручивает к элементу сам.

**5. Клик через JavaScript:**

```java
SelenideElement button = $(byText("Подтвердить"));
button.scrollIntoCenter().shouldBe(visible);
button.click(ClickOptions.usingJavaScript());

// или напрямую
executeJavaScript("arguments[0].click()", button);
```

**Почему JS-клик - крайняя мера.** Он нажимает и ту кнопку, на которую пользователь нажать не может: перекрытую, невидимую, неактивную. Так он прячет баг фронтенда или кривой локатор. Если в проекте JS-клики повсюду, тесты проверяют не то, что видит пользователь.

</details>
