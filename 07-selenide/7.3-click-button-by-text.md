# 7.3 · Клик по кнопке с текстом

🟡 надо подумать · тема: локаторы, клики

## Условие

Код должен нажать на кнопку с текстом «Подтвердить».

```java
import static com.codeborne.selenide.Selenide.$;

public class ButtonClickProblem {
    public static void main(String[] args) {
        // Находим кнопку
        $("button:contains('Подтвердить')").click();
    }
}
```

Вопросы интервьюера:
1. Почему кнопка может не кликаться?
2. Какие есть альтернативные способы кликнуть по кнопке в Selenide?
3. Как проверить, видна ли кнопка?
4. Как прокрутить страницу к кнопке, если она не в зоне видимости?
5. Как кликнуть через JavaScript, если обычный клик не работает?

<details>
<summary><b>Решение</b></summary>

**Главная ошибка: `:contains` не существует в CSS.** Этот псевдокласс взят из jQuery. Браузер его не понимает, поэтому Selenide упадёт с `InvalidSelectorException`. Его до сих пор советуют старые статьи, и он похож на CSS, поэтому такая ошибка встречается часто.

Правильно искать по тексту так:

```java
$(byText("Подтвердить")).click();                    // точное совпадение текста
$$("button").findBy(text("Подтвердить")).click();    // среди кнопок, по вхождению текста
```

**1. Почему кнопка может не кликаться:**
- локатор ничего не находит (наш случай);
- кнопка перекрыта другим элементом: модалкой, лоадером, баннером с куками;
- кнопка за пределами видимой области;
- кнопка ещё не отрисовалась, страница грузится асинхронно;
- кнопка неактивна (`disabled`).

**2. Альтернативные способы клика:**
`click(ClickOptions.usingJavaScript())`, клик со смещением `click(ClickOptions.usingDefaultMethod().offset(x, y))`, `doubleClick()`, `contextClick()`, клик через `actions()`.

**3. Видна ли кнопка:**
`$(...).shouldBe(visible)` ждёт появления до таймаута. `isDisplayed()` проверяет мгновенно, без ожидания.

**4. Прокрутка к кнопке:**
`scrollTo()` прокручивает так, чтобы элемент оказался у края экрана, `scrollIntoCenter()` (Selenide 7) ставит его в центр. Обычный `click()` в Selenide и так прокручивает к элементу сам.

**5. Клик через JavaScript:**

```java
SelenideElement button = $(byText("Подтвердить"));
button.scrollIntoCenter().shouldBe(visible);
button.click(ClickOptions.usingJavaScript());

// или напрямую
executeJavaScript("arguments[0].click()", button);
```

**Почему JS-клик — крайняя мера.** Он нажимает даже на кнопку, по которой живой пользователь нажать не может: перекрытую, невидимую, неактивную. То есть прячет либо баг фронтенда, либо кривой локатор. Если в проекте JS-клики повсюду, тесты проверяют не то, что видит пользователь.

</details>
