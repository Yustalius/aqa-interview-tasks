# 7.1 · Подсчет кнопок

Тема: коллекции, ассерты · сложность: легкая

## Условие

Код должен найти все кнопки на странице и вывести их количество. Есть ли ошибка? Если есть, как исправить?

```java
import static com.codeborne.selenide.Selenide.$$;
import static com.codeborne.selenide.Selenide.$;

public class ButtonsCounter {
    public static void main(String[] args) {
        // Находим все кнопки
        $$("button").shouldHave(size(3));

        // Выводим количество кнопок
        System.out.println("Количество кнопок: " + $$("button").size());
    }
}
```

Дополнительно: чем `size()` отличается от `shouldHave(size(n))`?

<details>
<summary><b>Решение</b></summary>

**1. Код не решает задачу.** `shouldHave(size(3))` ничего не находит, это проверка, что кнопок ровно три. А задача - посчитать кнопки и вывести число, сколько бы их ни было. Если кнопок четыре, код упадет на первой строке и до вывода не дойдет. Спроси интервьюера, зачем здесь ассерт. Если он не нужен, убери его.

**2. Не скомпилируется.** `size` не импортирован, нужен `import static com.codeborne.selenide.CollectionCondition.size;`. Импорт `$` при этом не используется.

**3. Нет открытия страницы.** Без `open(url)` коду негде искать кнопки.

**4. Локатор продублирован.** `$$("button")` написан дважды. Коллекцию лучше сохранить в переменную, чтобы локатор был описан в одном месте. Быстрее от этого не станет: коллекции в Selenide ленивые и ищут элементы при каждом обращении.

```java
import com.codeborne.selenide.ElementsCollection;

import static com.codeborne.selenide.Selenide.$$;
import static com.codeborne.selenide.Selenide.open;

public class ButtonsCounter {
    public static void main(String[] args) {
        open("https://example.com");

        ElementsCollection buttons = $$("button");
        System.out.println("Количество кнопок: " + buttons.size());
    }
}
```

Если проверка на три кнопки все-таки нужна, ее делают на той же переменной: `buttons.shouldHave(size(3))`.

**`size()` или `shouldHave(size(n))`.** `size()` возвращает количество в текущий момент, без ожидания. Если страница еще грузится, получишь 0. `shouldHave(size(n))` ждет: Selenide повторяет проверку до таймаута (по умолчанию 4 секунды), пока условие не выполнится. Поэтому для динамических списков в тестах сначала ждут нужный размер через `shouldHave`, а потом работают с элементами.

</details>
