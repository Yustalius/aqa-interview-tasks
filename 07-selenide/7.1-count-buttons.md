# 7.1 · Подсчёт кнопок

🟢 разминка · тема: коллекции, ассерты

## Условие

Код должен найти все кнопки на странице и вывести их количество. Есть ли ошибка? Если есть, как исправить?

```java
import static com.codeborne.selenide.Selenide.$$;
import static com.codeborne.selenide.Selenide.$;

public class ButtonsCounter {
    public static void main(String[] args) {
        // Находим все кнопки
        $$("button").shouldHave(size(3));

        // Выводим количество кнопок
        System.out.println("Количество кнопок: " + $$("button").size());
    }
}
```

Дополнительно: чем `size()` отличается от `shouldHave(size(n))`?

<details>
<summary><b>Решение</b></summary>

**1. Код не соответствует задаче.** `shouldHave(size(3))` ничего не «находит», это **проверка**, что кнопок ровно три. Задача же посчитать кнопки и вывести число, сколько бы их ни было. Если кнопок четыре, код упадёт на первой строке, и до вывода дело не дойдёт. Стоит спросить интервьюера, зачем здесь ассерт. Если он не нужен, его надо убрать.

**2. Не скомпилируется.** `size` не импортирован, нужен `import static com.codeborne.selenide.CollectionCondition.size;`. Импорт `$` при этом лишний.

**3. Нет открытия страницы.** Без `open(url)` коду негде искать кнопки.

**4. Локатор продублирован.** `$$("button")` написан дважды. Коллекцию лучше сохранить в переменную: локатор описан в одном месте, код читается проще. Коллекции в Selenide ленивые и всё равно ищут элементы при каждом обращении, так что выигрыш в читаемости, а не в скорости.

```java
import com.codeborne.selenide.ElementsCollection;

import static com.codeborne.selenide.Selenide.$$;
import static com.codeborne.selenide.Selenide.open;

public class ButtonsCounter {
    public static void main(String[] args) {
        open("https://example.com");

        ElementsCollection buttons = $$("button");
        System.out.println("Количество кнопок: " + buttons.size());
    }
}
```

Если проверка «кнопок ровно три» всё-таки нужна, её делают на той же переменной: `buttons.shouldHave(size(3))`.

**`size()` или `shouldHave(size(n))`.** `size()` возвращает количество **прямо сейчас**, без ожидания. Если страница ещё грузится, получишь 0 и пойдёшь дальше. `shouldHave(size(n))` — умное ожидание: Selenide повторяет проверку до таймаута (по умолчанию 4 секунды), пока условие не выполнится. Поэтому в тестах для динамических списков сначала ждут нужный размер через `shouldHave`, а потом работают с элементами.

</details>
