# Блок 7. Selenide: найди ошибку

Короткие сниппеты на Selenide. Формат как в блоке 1, но спрашивают не «что выведет», а «работает ли и как починить».

Правило блока: различай **ошибку компиляции**, **ошибку логики** и **плохую практику**. Это три разных ответа.

Общий подвох всех трёх задач: в коде нет `open(url)`. Не забудь спросить, на какой странице всё это происходит.
