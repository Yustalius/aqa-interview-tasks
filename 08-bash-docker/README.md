# Блок 8. Bash и Docker

Такие задачи дают реже, обычно в командах, которые много работают в Linux и сами поднимают окружение. Знать синтаксис наизусть никто не требует. Требуется спокойно прочитать чужой код и объяснить, что он делает.

Как читать, если синтаксис незнаком:
- ищи знакомое: `if`, `||`, `&&`, `==`, пути к папкам, переменные (`$BANK` как `${VAR}` в Jenkins);
- переводи ключевые слова буквально: `then` — «то», `else` — «иначе», `FROM`, `COPY`, `RUN`;
- сначала перескажи код целиком, потом говори о проблемах.
