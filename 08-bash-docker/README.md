# Блок 8. Bash и Docker

Такие задачи дают реже, обычно командам, которые много работают в Linux и сами поднимают окружение. Синтаксис наизусть не требуют, надо прочитать чужой код и объяснить, что он делает.

Если синтаксис незнаком, ищи знакомое: `if`, `||`, `&&`, `==`, пути к папкам, переменные (`$BANK`, как `${VAR}` в Jenkins). Ключевые слова переводи буквально: `then` - "то", `else` - "иначе", `FROM`, `COPY`, `RUN`.
